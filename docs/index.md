- 외국인/기관/프로그램 수급, KOSPI200 선물/베이시스, NXT 데이터는 수집하지 않아 미확인.
- VWAP은 누적 거래대금/누적 거래량 기반 근사치이며 체결별 실제 VWAP이 아님.
- 점수는 상대평가이며 상승확률이 아님. 진입/손절/목표는 참고값.
